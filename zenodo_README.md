# ClonalGE — benchmarking data and intermediate results

This Zenodo record contains the **input data**, **intermediate MCMC results**, and
**downstream analysis outputs** that accompany the ClonalGE manuscript:

> Shafighi, S., Jurzysta, B., Szczurek, E. *Inferring gene expression profiles of
> tumor clones*. (2026).

The **source code** for ClonalGE is hosted on GitHub:
<https://github.com/szczurek-lab/ClonalGE>.

A code archive corresponding to the version used in the paper is also archived
on Zenodo (separate record).

## 3. File formats

Each `Results_*` directory follows the convention used by `clonalGE.py` /
`tumoroscope.py`:

| File | Content |
|---|---|
| `inferred_vars_<section>_chain_<c>` | Pickled MCMC chain object (per-iteration latent variables, log-likelihood, batch sums) |
| `inferred_vars_<section>.txt` | Human-readable summary of post-burn-in posterior means |
| `all_h.npy`, `all_b.npy`, `all_n.npy` | Saved posterior-mean arrays for H (spots × clones), B (clones × genes), N (spots) |
| `all_h.txt`, `all_n.txt`, `all_z.txt` | Text exports of the same |
| `A.txt`, `D.txt` | Alternated and total mutation read counts (input recap) |
| `expr.csv` | Spot × gene expression matrix (input recap) |
| `genes_order.txt`, `spots_order.txt`, `mutations_order.txt` | Index orderings used by the saved arrays |
| `C_ik.csv`, `C_ik_clustered.png` | Clone–mutation genotype matrix |
| `log.txt` | Runtime, iteration count, convergence diagnostics |
| `visualization_all/` | Per-run convergence and posterior summary plots |

## 4. How to reproduce a figure

```bash
# 1. Install ClonalGE (from GitHub)
git clone https://github.com/szczurek-lab/ClonalGE
cd ClonalGE
pip install -r requirements.txt   # numpy, scipy, pandas, matplotlib, seaborn

# 2. Point the figure scripts at the deposit folders, e.g. for Fig. 3:
python plot_figure3.py \
    --result_prefix /path/to/clonalge_zenodo/02_clonalge_results/prostate_real/Results_figure5 \
    --num_runs 20 \
    --start_seed 1 \
    --section all
```

The same pattern works for `plot_figure4.py`, `plot_figure5.py`, `plot_figureS1_S2.py`,
`plot_figureS3.py`, `plot_stdeconvolve_comparison.py`, `plot_sensitivity.py`, and
`run_gsea.py`. See the GitHub repo's `README.md` for full command-line options.

## 5. Provenance

- ClonalGE inference was performed with the implementation tagged as the manuscript
  release on GitHub.
- Tumoroscope baseline (`Results_simulated_tumoroscope*/`) used the published
  Tumoroscope code (Shafighi et al., 2024) wrapped in `tumoroscope.py`.
- STdeconvolve baseline used `STdeconvolve` v1.x with default settings; topic-to-clone
  matching was performed via the Hungarian algorithm (`scipy.optimize.linear_sum_assignment`).
- All experiments were run on a single workstation (CPU only).
