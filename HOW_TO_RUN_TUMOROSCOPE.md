# How to Run Tumoroscope Comparison on the Cluster

Run Tumoroscope on the same 20 simulated datasets used by ClonalGE, then produce a side-by-side comparison figure.

---

## Step 1 — Pull the latest code on the cluster

```bash
cd /path/to/ClonalGE
git pull origin ongoing-changes
```

---

## Step 2 — Edit the SLURM script

Open `run_tumoroscope_simulated_slurm.sh` and fill in the four TODOs:

```bash
CLONALGE_DIR="/path/to/ClonalGE"           # e.g. /home/user/ClonalGE
TUMOROSCOPE_SRC="/path/to/Tumoroscope/src" # e.g. /home/user/Tumoroscope/src
RESULTS_DIR="/path/to/Results_simulated_tumoroscope/"

# Paired comparison: point to the test_sim/ folder from your ClonalGE runs
# (the folder generated by generate_simulations.sh).
# If it doesn't exist, fresh simulations are generated automatically.
export SIM_DIR="/path/to/test_sim"         # e.g. /scratch/user/test_sim
```

Then activate the ClonalGE conda environment. Uncomment **one** of the options
in the script that matches your cluster — for example:

```bash
# Option D (most reliable — use the explicit Python path):
PYTHON="/path/to/conda/envs/clonalge/bin/python"
```

---

## Step 3 — Submit the job

```bash
cd /path/to/ClonalGE
mkdir -p logs
sbatch run_tumoroscope_simulated_slurm.sh
```

This launches 20 array tasks (one per replicate). Each task runs all 3 conditions
(normal, low_variance, high_coverage) and takes up to 6 h / 8 GB RAM.

Monitor progress:
```bash
squeue -u $USER
tail -f logs/tum_<JOBID>_1.out   # replace with your actual job ID
```

---

## Step 4 — Check the results

After all jobs finish, each run directory should contain:

```
Results_simulated_tumoroscope/
  1/
    results_normal.txt
    results_low_variance.txt
    results_high_coverage.txt
  2/ ...
  20/ ...
```

Quick sanity check:
```bash
grep "Standard Error of the Estimate H" \
    /path/to/Results_simulated_tumoroscope/1/results_normal.txt
```

---

## Step 5 — Copy results back (if needed)

If you want to plot locally, rsync the results directory to your machine:

```bash
rsync -av cluster:/path/to/Results_simulated_tumoroscope/ \
    /Volumes/LenovoPS8/ClonalGE/Results_simulated_tumoroscope/
```

---

## Step 6 — Plot the comparison figure

```bash
cd /path/to/ClonalGE

python plot_simulated_results.py \
    --results_dir      /Volumes/LenovoPS8/ClonalGE/Results_simulated_data \
    --tumoroscope_dir  /Volumes/LenovoPS8/ClonalGE/Results_simulated_tumoroscope \
    --num_runs         20 \
    --output           plots_paper/figure_simulated_comparison.png
```

The figure is saved to `plots_paper/figure_simulated_comparison.png`.
It shows paired boxplots for H_SEE, phi_SEE, and pi_SEE
(ClonalGE = solid, Tumoroscope = hatched) across the 3 conditions.

---

## Notes

- **No new conda env needed** — Tumoroscope only uses numpy/scipy, which are
  already in the ClonalGE environment.
- **Paired comparison**: if `SIM_DIR` points to the existing `test_sim/` folder,
  both models run on exactly the same simulated data. If the folder is missing
  for a given run, a fresh simulation is generated automatically.
- **B_SEE is ClonalGE-only** (Tumoroscope has no gene expression), so it is
  omitted from the comparison figure.
